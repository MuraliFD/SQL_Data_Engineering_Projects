# 🏗️ Data Warehouse & Mart Build: Production ETL Pipeline

This project focuses on designing and creating a data warehouse / mart layer in SQL for analytical workloads.

## Project goal
- Build a star-schema style warehouse for reporting and BI use cases
- Create core dimension and fact tables for structured analytics
- Establish a clean foundation for downstream ETL and reporting tasks
